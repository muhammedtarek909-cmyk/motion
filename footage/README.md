# الفوتيج

كل حلقة في فولدر لوحدها:

| الحلقة | الفولدر | صور |
|---|---|---|
| الكوليرا 1947 | `cholera-1947/` | 394 |
| دنشواي 1906 | `denshawai-1906/` | 254 |

جوه كل فولدر:
- `SHOT_LIST.md` — كل جملة في الاسكريبت وعدد الصور بتاعتها، و⚠️ للمشاهد اللي محتاجة AI.
- `YOUTUBE_LINKS.md` — لينكات يوتيوب تنزّلها (نزّلها في `youtube/` جوه نفس الفولدر).
- `images/<رقم المشهد>/` — الصور، ومعاها `sources.json` فيه لينك كل صورة الأصلي.
- `shots.json` — تقسيم الاسكريبت وكلمات البحث (لو حبيت تعيد البحث: `python3 tools/fetch_images.py footage/<الحلقة>/shots.json`).
