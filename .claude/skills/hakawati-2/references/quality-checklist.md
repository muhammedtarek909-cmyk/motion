# قائمة المراجعة قبل التسليم

راجع بند بند. أي بند فاشل يبقى تعدّل النص، مش تسلّم وتعتذر.

## 1. الدقة
- [ ] كل اسم وتاريخ ورقم واقتباس ليه مصدر.
- [ ] الادعاءات المحورية متأكدة من مصدرين مستقلين (في حالة البحث).
- [ ] الأرقام المختلف عليها اتقالت بكل رواياتها وأصحابها.
- [ ] درجة اليقين محفوظة ("بيتحكي"، "غالبًا"، "حسب رواية")، ومفيش احتمال اتحول لحقيقة.
- [ ] كل "وبالتالي" وراها علاقة سببية موثقة، مش مجرد تزامن.
- [ ] مفيش حوار أو دافع نفسي مخترع لشخص حقيقي. أي كلام على لسان شخصية معلن إنه **ترجمة شعبية للموقف**.
- [ ] القلبة (لو موجودة) مبنية على معلومات موثقة.
- [ ] في الأحداث الجارية: تاريخ التغطية مكتوب، ومفيش تنبؤ قاطع.
- [ ] المقارنات المحلية (مساحات، أرقام) اتحسبت فعلًا.

## 2. بصمة حمزة
- [ ] الافتتاحية من نوع محدد (قسم 1)، **واتلعبت لحد نتيجة أو كشف حقيقي**. مفيش تجميد.
- [ ] الوعد فيه 3–5 حاجات محددة، **وكلهم اتوفّوا** بنفس الترتيب تقريبًا.
- [ ] الرجوع للماضي فيه مسافة وسبب، وصيغته مش منسوخة.
- [ ] السرد بعد الرجوع فيه قفزات زمنية معلنة، والمشاهد عارف هو في أنهي سنة.
- [ ] **المشهد الافتتاحي رجع** في مكانه الزمني، بتفصيلتين أو تلاتة منه.
- [ ] محرّك الجسم واضح (قسم 4)، ولو فيه عدد معلن (تلات عصافير، أربع حركات) كلهم اتغطوا.
- [ ] صوت المشاهد المعترض موجود بالمعدل الصح (3–6 في الفيديو اللي 15–20 دقيقة)، والصيغ متنوعة، وكل واحد بيبرر انتقال أو بيشرح حاجة.
- [ ] فيه محطات تلخيص كل 2–4 دقايق.
- [ ] "خلّي دي في بالك" مرة بالكتير، وكل زرعة رجعت.
- [ ] الختام من نوع محدد (قسم 7)، ومختلف عن آخر اسكريبت، ومفيش وعظ ولا تلخيص نقطي.

## 3. الصوت المصري
- [ ] **مفيش ولا كلمة شامية:** يلي، رح، هيك، هون، بدّي، شو، ليش، منيح، لهيك، زلمة، عم، حدا، هاد، هذول، هسه.
- [ ] مضارع مستمر للحكي، و"هـ" للاستباق.
- [ ] الاقتباسات الفصيحة في سطر لوحدها بين « »، وبعدها ترجمة شعبية.
- [ ] لقب المخاطبة مش أكتر من مرة كل 3–5 دقايق.
- [ ] مفيش جملة من جمل حمزة أو لوازمه بالنص (تقديمه، جملة انطلاقه، "يا صديقي العزيز" المتكررة).
- [ ] الهزار في الانتقالات وصوت المعترض والتفاصيل العبثية، و**صفر** عند لحظات الموت والضحايا.
- [ ] اقرأه بصوت عالي في دماغك: مفيش تركيب فصيح متعمّل ولا جملة بتقطع النفس.

## 4. الفقرات والفويس أوفر
- [ ] فقرات مرقّمة بعناوين فيها فضول، فقرة لكل دقيقة ونص لـ دقيقتين.
- [ ] الكلام المنطوق ماشي لو اتقري من غير العناوين.
- [ ] آخر كل فقرة (ما عدا الأخيرة) فيه خطّاف، والأنواع متنوعة، وكل خطّاف اتدفع في أول سطرين من الفقرة اللي بعده.
- [ ] سطر لكل جملة أو نَفَس، وسطر فاضي بين المجموعات.
- [ ] الأرقام والتواريخ مكتوبة **بالأرقام** (1956، 38، 120,000)، والكلمة اللي معاها بالحروف ("في المية"، "مليون").
- [ ] كل اسم شخص أو مدينة أو مكان أجنبي **بالإنجليزي وجنبه نطقه بالعربي بين قوسين، في كل مرة يظهر**. والأسامي العربية والدول المشهورة بالعربي.
- [ ] `…` والبولد بقلة.
- [ ] مفيش أقواس (غير أقواس النطق) ولا رموز ولا تعليمات مونتاج جوه الكلام المنطوق.

## 5. المدة والشكل
- [ ] عدد الكلمات ≈ الدقايق × 160 (± 10%)، والعناوين مش محسوبة.
- [ ] سطر **البناء** موجود (الافتتاحية · الجسم · الختام · السؤال اللي شادد الفيديو).
- [ ] قايمة الصور والخرايط موجودة لو النص بيشاور على الشاشة.
- [ ] المصادر برّه النص.
- [ ] مفيش اشترك/لايك/إعلان إلا بطلب.
